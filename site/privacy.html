Privacy policy · Updated 8 October 2026

Privacy, plainly.

Simple AI-Chat export for ChatGPT, Claude, Gemini is an independent project by @taiyodayo. It is not affiliated with OpenAI, Anthropic or Google.

Current availability

Production version 0.2.2 reads rendered ChatGPT, Claude and Gemini messages after you choose Export. Chrome Web Store approval and an install link are pending. Its separate browser demonstration uses sample conversations.

Conversation data

Formatting and file creation run in your browser. The extension has no analytics, advertising, error uploads, remote configuration or developer backend. It does not keep a conversation cache or use browser storage to retain conversation content.

The extension reads only the displayed conversation you choose, including guest chats, and processes it locally. It briefly scrolls the page to check stability. It does not make conversation API requests or read session cookies or provider authentication state. Secrets typed into a message can appear in its export. Conversation content is not sent to the developer, payment providers or other processing services. Server-side history completeness cannot be verified.

Your saved files

Exports are plain text or Markdown, with metadata at the beginning. Metadata includes the title, original conversation link, selected message identifiers, export date, message count and any omissions. Files are not encrypted. They stay wherever you save them until you remove them; uninstalling the extension does not remove your files or browser download history.

Temporary conversation data is held in memory during export and released afterwards. JavaScript cannot guarantee secure erasure of memory.

Browser permissions

Current tab: after you deliberately open the extension, it can check whether the chosen tab contains a supported saved conversation. This permission does not itself enforce a single-conversation boundary.

Downloads: a local file is handed to Chrome through a normal download link. No downloads permission is requested. Chrome manages completion and history; the extension cannot inspect it. Check Downloads to confirm that the file finished saving.

Optional Deep Research access: when a completed report needs access to its embedded sandbox site, the extension requests that exact app origin after you choose to allow it. Chrome retains this permission until you remove it in extension settings. The exporter reads report Markdown and citations already loaded in the chosen chat; it does not fetch source pages or research activity.

Selected save folder: choosing a custom folder grants access through Chrome’s native picker. The exporter checks candidate export filenames and writes your file without reading other files or listing the directory. The folder handle is kept only in the export window’s memory. These saves do not appear in Chrome’s download history.

This website

This site uses no analytics, tracking cookies, embedded payment widgets or remote fonts. Cloudflare hosts and protects it. Cloudflare may process ordinary connection information, such as IP addresses, requested URLs and browser information, to deliver and secure the site. Provider logs are subject to Cloudflare’s policies; we do not promise that visiting a website leaves no network records.

Optional support

Buy Me a Coffee opens only when you choose its link. The link contains no conversation text, titles, identifiers or tracking parameters and sends no referrer. The payment provider receives ordinary connection information and applies its own privacy practices. We do not handle your card details.

For help, use GitHub issues or the support page. GitHub processes anything you choose to submit under its own policies; public issues are visible to others. Never include passwords, authentication tokens or private conversation files.

If you email chat-simple-export@ongaku.co.uk, Cloudflare Email Routing forwards your message to the project owner's mailbox. Cloudflare and the mailbox provider process your email address and message for delivery, and the owner receives what you choose to send. This is optional support; the extension does not send conversation data by email. Never include credentials or private conversation files.

Limited use

The extension does not upload your conversation data anywhere. Processing happens in-browser. You can check how this works in the source code on GitHub.

The source is public for security inspection under MIT + Commons Clause v1.0, with credit to @taiyodayo. Source availability is not a claim of an external security audit.

Conversation data is not sold, used for advertising, or used to build profiles. Our use of user data adheres to the Chrome Web Store User Data Policy, including its Limited Use requirements.
