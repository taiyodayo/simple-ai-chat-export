A little practical help

Before you export.

How will I install it?

The Chrome Web Store will be the main installation route. Once the verified release is available, this page will link directly to its listing. No store listing is live yet.

After installation, open your conversation and choose Simple ChatGPT Export from the browser’s Extensions menu. Pin it there if you’d like it close to hand. No onboarding tour required.

What if I open it on another website?

Export will work with signed-in and guest conversations at chatgpt.com. On an unsupported page, it asks you to open a ChatGPT conversation. Nothing is read or saved.

Which browsers will it support?

We’re targeting desktop Chrome on macOS, Windows and Linux. Other Chromium browsers will be listed once tested. Mobile browsers are outside the initial scope.

What will be in my download?

An editable Markdown or plain-text file with metadata at the beginning. Metadata records the title, original conversation link, export date, selected message identifiers, message count and omissions. The file is not encrypted.

Images, audio, video and attachment files are not downloaded. A text-only export marks their places. The original conversation remains unchanged.

What if an export cannot be completed?

The extension will explain the problem and avoid claiming success. Wait for ChatGPT to finish replying, check your connection, and try again on the branch you want. If saving was interrupted, check Downloads before retrying.

Do I need to pay?

No. The coffee link is an optional way to support the project. It never unlocks features or blocks an export.

How do updates work?

A store installation may update automatically through your browser. A manually loaded copy updates when you replace its local files. Release notes and matching source will accompany public releases.

How can I get help or report a security issue?

The support address is being set up before public release. When active, it will be listed here. Please include your browser, operating system, extension version and the message you saw. Never send passwords, authentication tokens or private conversation files.
