A little practical help

Before you export.

How do I install it?

The Chrome Web Store install link will appear after approval. No store listing is live yet. Until approval, download the release ZIP from GitHub releases, extract it, then choose Load unpacked in chrome://extensions with Developer mode enabled.

After installation, open your conversation and choose Simple AI-Chat export from the browser’s Extensions menu. Pin it there if you’d like it close to hand. No onboarding tour required.

What if I open it on another website?

The extension recognises saved conversations at chatgpt.com, claude.ai and gemini.google.com, plus ChatGPT guest chats. On an unsupported page, it asks you to open a supported conversation. Nothing is read or saved.

Which browsers does it support?

Desktop Chrome on macOS has been tested. Windows, Linux and other Chromium browsers are not independently verified yet. Mobile browsers are outside the current scope.

What is in my download?

An editable Markdown or plain-text file with metadata at the beginning. Metadata records the title, original conversation link, export date, selected message identifiers, message count and omissions. The file is not encrypted.

Images, audio, video and attachment files are not downloaded. A text-only export marks their places. The original conversation remains unchanged.

Does it include reports and artifacts?

Supported completed ChatGPT Deep Research reports include Markdown and citations. Claude artifacts, Gemini Canvas and other content outside messages are not archived. Gemini Deep Research is not yet verified. Rendered exports cannot prove server-side history completeness.

What if an export cannot be completed?

The extension will explain the problem and avoid claiming success. Wait for the app to finish replying, check your connection, and try again on the branch you want. If saving was interrupted, check Downloads before retrying.

Do I need to pay?

No. The coffee link is an optional way to support the project. It never unlocks features or blocks an export.

How do updates work?

A store installation may update automatically through your browser. A manually loaded copy updates when you replace its local files. Release notes and matching source will accompany public releases.

How can I get help or report a security issue?

Report ordinary bugs through GitHub issues, or email chat-simple-export@ongaku.co.uk. For security issues, use private vulnerability reporting. Include your browser, operating system, extension version and a synthetic reproduction. Never send passwords, authentication tokens or private conversation files.
